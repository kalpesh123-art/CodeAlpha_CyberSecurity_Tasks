# CodeAlpha Cybersecurity Internship Tasks

This repository contains all completed tasks for the CodeAlpha Cybersecurity Internship program.

## 📋 Task Overview

1. **Task 1: Basic Network Sniffer** (`task1_network_sniffer.py`) 
   * Captures live network packets using Python and Scapy.
   * Extracts source/destination IP addresses, protocol types (TCP, UDP, ICMP), and payload previews.

2. **Task 2: Phishing Awareness Training** (`TASK2_PHISHING_AWARENESS.md`) 
   * A comprehensive training module detailing phishing attacks, social engineering red flags, and real-world attack scenarios.
   * Covers mitigation and prevention best practices.

3. **Task 3: Network Intrusion Detection System (NIDS)** (`task3_nids_simulation.py`) 
   * Monitors live network traffic and flags abnormal SYN packet spikes to detect potential port scans or SYN floods.

4. **Task 4: Secure Code Review & Audit** (`TASK4_SECURE_CODE_AUDIT.md`) 
   * An audit report identifying critical SQL Injection (SQLi) vulnerabilities in application source code.
   * Provides remediation strategies using parameterized queries/prepared statements.
